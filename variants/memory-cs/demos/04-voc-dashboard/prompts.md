## 시연 프롬프트

> 이 폴더의 customer_emails_6mo/ 안에 있는 모든 .txt 파일을 읽어줘.
> 고객사별로 다음을 추출해서 voc_profile.md 만들어줘:
>
> 1. 기본 프로필 (주 컨택 부서·메일 빈도·평균 응답 기대·평균 길이·톤)
> 2. 자주 묻는 Top 3 (빈도 % 포함)
> 3. 톤 특성 (선호/비선호)
> 4. 자동 추천 응대 가이드
> 5. 최근 핫이슈
>
> 마지막에 횡단 인사이트:
> - 응답 우선순위 자동 분류
> - 응답 톤 자동 매칭
> - 다음 분기 예상 주제
>
> 한국어. 데이터로 확인되는 것만, 추측 코멘트 금지.

## 시연 흐름 (2분)

### 0:00~0:30 — 입력 보여주기
- "고객사 3사 메일 6개월치 60통이 있다고 칩시다 (지금은 샘플 9통)"
- `customer_emails_6mo/` 폴더 트리 보여주기
- 메일 1~2개 빠르게 스크롤 (X·Y·Z 각각 다른 톤이 보이는지)

### 0:30~1:00 — 프롬프트 입력
- 강사가 입력
- "이런 한 줄로..."

### 1:00~2:00 — 결과 보여주기
- `voc_profile.md` 3개 카드 빠르게 스크롤
- 핵심 인사이트 짚기:
  - "Customer X: 엔지니어링 중심, spec 인용 강조"
  - "Customer Y: 일정 민감, 당일 답 필요"
  - "Customer Z: 장기 파트너십, 깊이 있는 답"
- **메시지**: "신입이 바로 선배 수준 답장 — 매뉴얼 자동 추출"
- **연결**: "Day 2에서 신규 메일 들어오면 자동으로 톤 매뉴얼 적용"
