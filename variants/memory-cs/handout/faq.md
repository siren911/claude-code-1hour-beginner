## 보안·NDA (가장 중요)

### Q1. 고객 lot ID 진짜 입력해도 돼요?
**A.** **반드시 사내 IT/보안 가이드를 먼저 확인하세요.** 본 자료 기준으로는:
- 가상 데이터 (예: ABC-2025-K42) → ✅ OK
- 실 lot ID → ❌ 사내 가이드 명시적으로 허용한 범위 안에서만
- 의심스러우면 → 사내 보안팀 문의

### Q2. 데이터시트 원본을 그대로 넣어도 돼요?
**A.** ❌ **금지**. NDA 위반 가능성 매우 높음.
대신:
- ✅ Datasheet 일반 spec 표기 ("DDR5 8Gb", "1e-8 BER spec") 까지만
- ✅ 데이터시트 인용 시 "rev 1.3, section 4.2.1" 식 출처만 표기

### Q3. 미공개 spec / 다음 양산 일정도 안 돼요?
**A.** ❌ 절대 금지. 사내 미공개 정보 + 영업 비밀 + 잠재적 주가 영향 가능성.
대신:
- ✅ "확정된 일정" 만 (예: ECC v2 6/1 적용 — 이미 결정된 사항)
- ❌ "검토 중인 일정", "내부 논의 단계" 정보

### Q4. ChatGPT랑 Claude Code 어느 게 더 안전해요?
**A.** 둘 다 외부 LLM. 핵심은:
- 사내 ChatGPT (엔터프라이즈 계약) — 학습 미사용, 사내 가이드 따라야
- Claude Code (엔터프라이즈) — 동일
- 본 자료는 회사가 **Claude Code 사용을 승인했다는 전제**
- 어느 도구든 NDA 데이터 입력은 ❌

### Q5. 보안 사고가 났다면?
**A.** 즉시:
1. 작업 중단
2. 사내 IT/보안팀 즉시 신고
3. 어떤 데이터를 어디에 입력했는지 정확히 기록
4. 임의 삭제·은폐 절대 금지 (조사 협조)

## 사용 방법

### Q9. 영문 메일 작성이 너무 formal해서 부자연스러우면?
**A.** 고객별 톤 매뉴얼 보강:
```
customer_tone/[고객명].md
```
- 자주 쓰는 패턴 / 금지 표현 명시
- 매뉴얼 있으면 결과 품질 급상승

### Q10. AI가 spec 수치 틀리면 어떻게 알아요?
**A.** 3단계:
1. 프롬프트에 정확한 수치·datasheet rev 명시
2. AI 결과 받으면 **반드시** datasheet 원본 대조
3. 시니어 검토 후 발송 (절대 검토 없이 발송 X)

### Q11. 답이 영어로 와요.
**A.** 폴더 `CLAUDE.md`에 "한국어로 답변" 한 줄. 단, 영문 메일은 영문 유지.

### Q12. 컨텍스트가 너무 길어지면?
**A.** `/clear`로 초기화. 큰 작업은 단계 나누기 (분석 → 작성 → 검토).

## 직무별

### Q13. 회의록 작성에서 어디까지 자동화돼요?
**A.** 시연 기준:
- ✅ 메모 → 정리된 markdown
- ✅ 액션 아이템 표 (담당·기한)
- ✅ 결정사항 분리
- ❌ 참석자 의도 추측·정치적 함의 — 사람의 영역

### Q14. 고객 메일 회신은 어디까지 안전해요?
**A.** 안전한 범위:
- ✅ 영문 표현·문법·톤 정리
- ✅ 사내 FA 요약을 바탕으로 한 4섹션 답변 골격
- ✅ 한글 사내 공유용 요약
- ❌ **검토 없이 발송 절대 금지**
- ❌ 미확정 사항을 확정인 것처럼 답하기

### Q15. 대쉬보드는 진짜 자동 생성돼요?

## 솔직한 한계

### Q18. 안 되는 건 뭐예요?
**A.**
- ❌ 보드/실 양산 환경에서의 최종 검증
- ❌ Datasheet 진짜 의미·hidden meaning
- ❌ 회사 정치·내부 의사결정 추측
- ❌ 비결정성 (같은 질문에 답이 100% 같지 않음)
- ❌ 사내 가이드 위반 데이터 처리

### Q19. AI가 사람을 대체하나요?
**A.** "복붙으로 끝나던 작업"은 대체합니다. 하지만:
- 사람의 판단·관계·문맥 이해는 그대로
- 시니어의 가치는 "검토할 줄 아는 능력"으로 이동
- 주니어의 가치는 "AI를 잘 부리는 능력"이 추가됨
- 결과: 사람당 처리량 ↑, 일자리 자체는 직무 재정의

### Q20. 우리 팀이 이걸 다 채택하려면 얼마나 걸려요?
**A.** 패턴:
- 1주차: 개인이 30분/일 절감
- 1개월차: 팀 공통 CLAUDE.md 정착
- 3개월차: 일상 워크플로우 통합 (회의록·메일 자동화 표준)
- 6개월차: Day 2 자동화로 본격 시간 절감
- 1년차: 사내 다른 부서로 확산
