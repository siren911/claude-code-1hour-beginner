# 자주 묻는 질문 (FAQ)

> 세미나 Q&A에서 자주 나오는 질문 + 답

---

## 비용·계정

### Q1. 돈 들어요?
**A.** 첫 사용은 무료 한도 안에서 가능합니다. 본격적으로 매일 쓰면 월 USD 단위 비용. ChatGPT Plus($20)와 비슷한 감각이라 생각하시면 됩니다. 회사에서 쓰려면 엔터프라이즈 플랜이 별도로 있습니다.

### Q2. 신용카드 등록해야 해요?
**A.** 무료 한도까지는 보통 등록 없이 가능하지만, API 키 발급 시 필요할 수 있습니다. Anthropic 콘솔에서 한도 설정 가능 — 예: "월 $5 이상 못 쓰게" 설정.

### Q3. ChatGPT가 더 싸지 않아요?
**A.** ChatGPT는 텍스트 답변이 전부, Claude Code는 **파일을 직접 수정**합니다. 회의록·CSV·문서를 "복붙 없이" 디스크에 저장된 결과물로 받는 게 핵심 차이. 작업 시간을 시급으로 환산하면 더 쌉니다.

## 보안·프라이버시

### Q4. 회사 자료 넣어도 보안 괜찮아요?
**A.** 3가지 옵션:
1. **개인 계정**: 학습에 사용될 수 있음 → 회사 자료 비추
2. **API 직접 호출**: 학습 미사용 가능 (Anthropic 정책 확인)
3. **엔터프라이즈 플랜**: 학습 미사용 + 보존정책 통제 + 감사 로그

회사 NDA 코드라면 사내 보안팀 확인 후 사용하세요.

### Q5. 비밀번호·API 키도 가르쳐줘도 돼요?
**A.** 절대 금지. AI에 시크릿을 입력하지 마세요. `.env`, `credentials*` 같은 파일은 자동으로 무시되도록 설정 가능합니다.

### Q6. 인터넷 안 되면 안 돼요?
**A.** 네, Claude는 인터넷이 필요합니다. 로컬에서만 동작하는 LLM은 따로 있지만(Llama·Mistral 등) Claude Code 자체는 클라우드 호출 기반입니다.

## 사용 방법

### Q7. 코드 한 줄도 모르는데 정말 쓸 수 있어요?
**A.** 데모 1·2(회의록·CSV)가 바로 그 답입니다. 코드 없이 "대화"만으로 파일을 만들고 수정합니다. PM·기획자·학생이 가장 빨리 효과를 봅니다.

### Q8. AI가 잘못된 답 주면 어떻게 알아요?
**A.** 3단계:
1. **검토 가능한 결과물**: AI에게 "변경 내역을 changes.md에 적어줘" → 무엇을 했는지 추적
2. **가드레일 프롬프트**: "확실하지 않으면 '확인 필요' 표시" → AI가 자기 한계 인정
3. **사람 검토**: 중요한 결과는 항상 사람이 확인. AI는 "검토 시작점"을 0%→70%로 올려줄 뿐.

### Q9. 답이 영어로 와요.
**A.** 폴더에 `CLAUDE.md` 파일을 만들고 "한국어로 답변" 한 줄 적으세요. 매 대화마다 자동 적용됩니다.

### Q10. 컨텍스트가 너무 길어지면?
**A.** `/clear` 명령으로 대화 초기화. 큰 작업은 작게 쪼개서 시키는 게 좋습니다 ("회의록 → 액션만 추출 → 이메일 초안" 식으로 단계 분리).

## 다음 단계

### Q11. 다음에는 뭘 배워야 해요?
**A.** 추천 순서:
1. **CLAUDE.md 고도화** — 우리 팀 양식·규칙 적기
2. **Skills** — 자주 하는 작업을 명령어로 (`/회의록`, `/주간리포트`)
3. **MCP** — Claude가 우리 회사 시스템(Notion·Slack·GitHub)에 직접 접근
4. **Subagents·Hooks** — 자동화 (커밋 전 자동 검토 등)

→ [상급자 자료](https://jhl-labs.github.io/claude-code-1hour/) 참고. 단, 비개발자에겐 §1~§2까지만 필요할 가능성 큼.

### Q12. 어디서 도움을 받아요?
**A.**
- [Claude Code 공식 문서](https://docs.claude.com/) — 영문이지만 가장 정확
- 자료 GitHub Issue — 이 자료에 대한 질문
- 회사 슬랙에 "#claude-code" 채널 만들기 — 동료들과 노하우 공유

## 솔직한 한계

### Q13. 안 되는 건 뭐예요?
**A.**
- ❌ 보드/하드웨어 위 실제 검증 (사람만 가능)
- ❌ 데이터시트의 진짜 의미 (사람만 압니다)
- ❌ 비결정성 — 같은 질문에 답이 100% 같지 않음
- ❌ 환각 — `CLAUDE.md`가 부실하면 그럴듯한 거짓말 가능

### Q14. AI가 사람 일자리 다 가져가나요?
**A.** "복붙으로 끝나던 일"은 가져갈 수 있습니다. 하지만 "맥락을 주고·검토하고·결정하는" 일은 사람만 합니다. AI를 잘 쓰는 사람이 못 쓰는 사람보다 빨라질 뿐.
