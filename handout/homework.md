# 숙제 — 오늘부터 1주일

> 세미나만 듣고 끝나면 다음 주에 다 잊습니다. 다음 단계만 따라하세요.

---

## 오늘 끝나고 30분 (필수)

### Step 1 — 설치 (5분)
1. Node.js 깔려 있는지 확인:
   ```bash
   node -v
   ```
   - 안 깔렸으면 → [nodejs.org](https://nodejs.org) LTS 받기

2. Claude Code 설치:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

3. 로그인:
   ```bash
   claude login
   ```

### Step 2 — 첫 실행 (5분)
1. 빈 폴더 만들기:
   ```bash
   mkdir ~/claude-test
   cd ~/claude-test
   ```

2. Claude 실행:
   ```bash
   claude
   ```

3. 첫 프롬프트:
   > 이 폴더에 hello.md 파일 만들어줘. 인사말 한 줄.

4. 결과 확인 — 폴더에 `hello.md`가 생겼는지

### Step 3 — 진짜 작업 1개 (20분)
자기 일에서 "텍스트로 정리해야 하는 귀찮은 거" 1개 선택:

| 직군 | 추천 작업 |
|---|---|
| PM·기획자 | 이번 주 회의 메모를 회의록으로 |
| 학생 | 강의 노트를 시험 요약본으로 |
| 부트캠프 | 어제 강의 핵심 5가지를 markdown으로 |
| 일반인 | 지난 주 일기 7개를 한 주 요약으로 |

→ `claude`로 시켜보고 결과가 어떤지 확인.

---

## 내일까지 (10분)

### CLAUDE.md 만들기

`~/claude-test` 폴더에 `CLAUDE.md` 파일 생성:

```markdown
# 내 작업 환경

- 직업: [당신의 직업]
- 자주 만드는 결과물: [예: 회의록, 리포트, 일정 정리]
- 좋아하는 톤: [예: 간결, 표 위주, 친근한]
- 한국어로 답변
- [당신만의 규칙 — 예: "이모지는 회의록에는 쓰지 않기"]
```

### 다시 한 번 시켜보기

`CLAUDE.md`가 있는 폴더에서 `claude` 실행 →  
어제 시킨 작업을 다시 시켜보고 결과가 어떻게 달라지는지 비교.

## 1주일 안 (1~2시간)

### 친한 동료에게 시연

- 옆 자리 한 명에게 5분 시연
- 같이 따라하게 하기
- 이게 진짜 성장 가속 — 누군가에게 설명하면서 본인이 더 잘 알게 됩니다.

### 우리 팀에 맞는 CLAUDE.md 만들기

- 우리 팀이 자주 쓰는 양식 적기
- 금지 사항 (예: "고객 이름 절대 첨부하지 않기")
- 한 폴더에 두고 팀 공유 (Notion·Google Drive)

---

## 2주차 이후 (선택)

- `/permissions` 명령 익히기 — 위험한 명령 미리 차단
- VS Code 안에서 Claude Code 쓰기 — 통합 워크플로우
- [상급자 자료](https://jhl-labs.github.io/claude-code-1hour/) 보기 — 코드 작업이 필요해진 시점에

## 막힐 때

| 증상 | 1차 대응 |
|---|---|
| 설치 안 됨 | Node.js 버전 확인 (18 이상) |
| 답이 영어 | `CLAUDE.md`에 "한국어로 답변" |
| 답이 엉뚱 | `/clear` 후 다시, 또는 프롬프트 더 구체적으로 |
| 파일 못 만듦 | `/permissions`에서 허용 |
| 비용 걱정 | 첫 사용은 무료 한도. `claude --help`로 한도 확인 |

→ [FAQ](faq.md)도 보세요.
