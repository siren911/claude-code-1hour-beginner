> 강사 시연용. 진행 시간: 13분 (32:00~45:00)

## 프롬프트 1 — 문제 진단

> 이 폴더의 messy.csv 파일을 읽고 각 행의 문제점을 표로 정리해줘.
> 표 항목: 줄 번호 / 문제 유형 / 비고
> 의심스럽지만 확실하지 않은 건 "확인 필요" 표시해줘.

### 예상 출력

| 줄 | 문제 | 비고 |
|---|---|---|
| 3 | 이메일 공백, amount 빈칸 | `kimcs @example.com` |
| 4 | 도메인 오타 추정 | `exampl.com` → `example.com`? **확인 필요** |
| 5 | 2행과 중복 | 동일 행 |
| 6 | 이메일 형식 오류 | TLD 없음 |
| 7 | name 빈칸 | |
| 8 | amount 숫자 아님 | 'abc' |
| 11 | 2행과 중복 | 동일 행 |

---

## 프롬프트 2 — 정리 실행

> 발견한 문제를 다음 원칙으로 정리해서 clean.csv와 changes.md를 만들어줘.
>
> 원칙:
> - 공백·중복은 자동 처리 OK
> - 도메인 오타는 보수적으로 수정하되 changes.md에 "확인 필요" 표시
> - 금전 데이터(amount)는 자동 추측 금지. 이상하면 행 자체를 제거하거나 빈칸 유지
> - 처리 내역은 changes.md에 어떤 행을 어떻게 했는지 표로
>
> clean.csv에는 정상 데이터만 남기되, 도메인 수정한 행은 포함해줘 (changes.md에 표시되니까).

### 예상 출력

- `clean.csv`: 5행 + 헤더 (유지 4 + 도메인 수정 1)
- `changes.md`: 처리 내역 + 사람 검토 필요 항목 + 처리 원칙
