# Demo 2 — 데이터 정리

엉망인 CSV(`messy.csv`)를 깔끔한 데이터(`clean.csv`)와 변경 내역(`changes.md`)으로 분리하는 시연.

## 파일

| 파일 | 용도 |
|---|---|
| [messy.csv](messy.csv) | 입력 — 오류·중복·공백이 섞인 데이터 |
| [clean.csv](clean.csv) | 기대 출력 — 정리된 데이터 |
| [changes.md](changes.md) | 기대 출력 — 변경 내역 + 사람 검토 필요 항목 |
| [prompts.md](prompts.md) | 강사 시연 스크립트 |

## 핵심 학습 포인트

1. **2단계 프롬프트**: 진단 → 정리 (한 번에 다 시키지 않고 검토 가능하게)
2. **AI에게 원칙 주기**: "금전 데이터 자동 추측 금지" 같은 가드레일
3. **검토 가능한 산출물**: `changes.md`로 AI가 무엇을 어떻게 바꿨는지 추적 가능

## 시연 시간

13분 (세미나 §3 데모 2)

## 메시지

> "엑셀 1시간 → AI 1분. 단, 결과 검토는 사람의 몫. AI에게 '추측 금지' 원칙을 주는 게 좋은 프롬프트."
