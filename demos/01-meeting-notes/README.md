# Demo 1 — 회의록 정리

회의 메모(`before.txt`)를 깔끔한 회의록(`after.md`)으로 정리하는 시연.

## 파일

| 파일 | 용도 |
|---|---|
| [before.txt](before.txt) | 입력 — 회의 메모 원본 |
| [after.md](after.md) | 기대 출력 — 정리된 회의록 |
| [prompts.md](prompts.md) | 강사 시연 스크립트 (프롬프트·진행 흐름) |

## 청중이 집에서 따라하는 법

1. 빈 폴더 만들고 `before.txt`를 복붙
2. 그 폴더에서 `claude` 실행
3. [prompts.md](prompts.md)의 메인 프롬프트 입력
4. 생성된 `after.md` 확인

## 시연 시간

12분 (세미나 §3 데모 1)

## 메시지

> "한 시간 걸리던 작업이 1분. 게다가 형식까지 맞춰서."
