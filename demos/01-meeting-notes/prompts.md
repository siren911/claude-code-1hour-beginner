# 데모 1 — 회의록 정리 프롬프트 스크립트

> 강사 시연용. 청중에게는 슬라이드로만 보여줌.

## 진행 시간: 12분 (20:00~32:00)

---

## 메인 프롬프트

> 이 폴더의 before.txt는 회의 메모야.
> 깔끔한 회의록 markdown 파일 after.md로 만들어줘.
> 다음 섹션 구조로:
> 1. 회의 정보 (일시·참석자)
> 2. 핵심 논의 (1~2문단 요약)
> 3. 결정사항 (표)
> 4. 액션 아이템 (담당·작업·기한 표)
> 5. 다음 회의 정보
>
> 기한이 명시된 건 그대로 적고, 명시 안 된 건 "별도 협의"로 표시해줘.

## 예상 Claude 행동

1. Read tool로 `before.txt` 읽음
2. 구조 분석 후 markdown 생성
3. Write tool로 `after.md` 저장
4. 결과 요약 출력

## 시연 흐름 세부

### 0:00~2:00 — 상황 설명
- "방금 회의 끝나고 메모만 적어둔 상황입니다"
- `before.txt` 텍스트 에디터로 열어서 보여주기
- "이대로 슬랙에 올리면 동료들이 못 읽죠"

### 2:00~5:00 — 강사 시연
- 터미널에서 `claude` 실행
- 메인 프롬프트 입력
- Claude가 일하는 화면을 청중에게 보여주기 (Read → Write 호출 흐름)

### 5:00~8:00 — 결과 확인
- `after.md` 파일 텍스트 에디터로 열기
- "어, 표도 만들어줬네"
- "기한도 자동으로 알아챘네 (5/20, 5/27)"
- 청중이 직접 비교할 수 있도록 화면 분할

### 8:00~10:00 — 변형 프롬프트
> 5월 27일 다음 회의 안건도 추측해서 3가지 적어줘.
> 오늘 결정사항을 기반으로.

- 예상 답: 검색 PRD 진행상황 점검 / 결제 모듈 분석 결과 공유 / 6월 일정 확정
- "오, 이건 추측이지만 합리적이네"

### 10:00~12:00 — 한계 강조
- "ChatGPT로도 정리는 됩니다"
- "차이점은 → ChatGPT는 텍스트를 줄 뿐, Claude Code는 파일을 직접 만들고 저장합니다"
- "회의 끝나고 슬랙에 바로 올릴 수 있는 형태로 디스크에 있다는 게 핵심"
